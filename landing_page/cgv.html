3. Produit

Le pack Uko est un contenu numérique fourni sans support matériel. Il comprend :

  • le moteur d’animation Uko (fichier JavaScript sans dépendance, utilisable comme Web Component <uko-mascot>, en JavaScript ou dans React) ;
  • trois personnages (Uko, Aituko, Meowuko) et leurs 9 états animés (idle, welcome, thinking, loading, success, error, empty, sleep, wake), une marche et un demi-tour, 17 coiffures pour Uko et des couleurs personnalisables ;
  • les fichiers Rive (.riv) des trois mascottes (Uko, Aituko, Meowuko) avec leur machine à états, et des exemples d’intégration ;
  • la documentation, et la licence d’utilisation commerciale perpétuelle.

Compatibilité : navigateurs récents (Chrome, Edge, Firefox, Safari) ; React 18 ou plus pour le composant React ; les runtimes officiels Rive pour le fichier .riv. Aucune connexion à un service tiers n’est nécessaire pour utiliser le pack. Les caractéristiques essentielles sont présentées sur la page d’accueil du Site, avec une démonstration en direct.
